En TipQR cuidamos tus datos. Esta política explica qué información recolectamos, para qué la usamos y cómo la protegemos.

1. Datos que recolectamos

  • Datos de registro: nombre, apellido, email, teléfono, CUIT y DNI.
  • Datos del comercio: razón social, rubro, dirección y documentación de validación.
  • Datos operativos: sucursales, empleados, mesas, grupos y registros de propinas.
  • Datos de pago gestionados por Mercado Pago (no almacenamos datos de tarjetas).

2. Para qué usamos los datos

Utilizamos la información para operar la Plataforma: crear y validar cuentas, generar códigos QR, registrar y conciliar propinas, distribuirlas entre el personal y mostrar reportes al comercio. No vendemos tus datos a terceros.

3. El cliente que deja propina

El cliente que escanea un QR y deja una propina no necesita registrarse. No recolectamos sus datos personales; el pago lo procesa Mercado Pago de forma independiente.

4. Seguridad

Aplicamos medidas razonables para proteger la información: contraseñas cifradas, autenticación por token y control de acceso por rol. Ningún sistema es 100% infalible, pero trabajamos para minimizar los riesgos.

5. Tus derechos

Podés solicitar acceder, rectificar o eliminar tus datos personales escribiéndonos. Atenderemos tu pedido conforme a la normativa vigente de protección de datos.
